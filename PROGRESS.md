- 2026-10-21: `HalfFloatImage` export frames are premultiplied linear RGBA. Accepted: translucent export content is rare (transparent sources with the Frosted background) and the difference is below one 8-bit code at the dark end. `Lanczos3`/`LumaSharpen` still assume straight alpha; they only run on opaque paths.
