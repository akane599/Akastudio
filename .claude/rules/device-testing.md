# Device testing on the shared emulator

- Run `adb devices` before deciding a change can't be device-tested. A shared redroid Android 15 emulator (`emulator-5554`) is normally attached and approved for AkaStudio.
- Code touching device-only APIs (ContentResolver/MediaStore, ExifInterface on real files, GL/EGL, MediaPipe/LiteRT, platform codecs, Compose window/BACK behaviour) needs an instrumented test in the module's `src/androidTest`, run on the emulator. JVM and screenshot tests alone don't verify those seams.
- Wrap every adb or `connected*AndroidTest` command in the device lock: `ANDROID_SERIAL=emulator-5554 flock $HOME/.cache/akastudio-emulator-5554.lock <command>`. One worker owns the device at a time.
- On the device, install/uninstall only `com.akane.akastudio` and its `.test` instrumentation packages. Never touch `com.akane.inspiration` or other apps, and never change global settings. Test media goes under `/sdcard/Pictures/AkaStudioQA/` or `/sdcard/Download/`. On the phone, galleries and other non-social apps may be used for display checks; social media and messaging apps (Instagram, WhatsApp, Telegram, Discord, Messages, Snapchat) need the user's explicit permission each time, and nothing is ever sent, posted or uploaded.
- The emulator renders GL in software (SwiftShader). Physical-GPU and HDR-display evidence needs the user's phone, and phone access is authorized per session only.
- A device test that exposes a product bug stays failing and gets reported; never delete or `@Ignore` it to go green.
- On an ADB-over-TCP serial (`host:port`, e.g. the phone), AGP 9.4.1's `connected*AndroidTest` fails even when every test passes; take the verdict from `TEST-*.xml` or a raw `am instrument -r -w` run, never from that Gradle exit code (`docs/stabilization/PHONE_QA_20261102.md`).
- The user uses the phone live (Haven SSH terminal): check the focused window before any key event, and send none while a personal app is in front.
- Procedures (lock-taking test runner and XML verdict, UiAutomation/mobilecli, focus check, peak RSS, thermal, HDR headroom) live in the `device-qa` skill; heavy device runs go to the `device-runner` agent. `.claude/hooks/guard-bash.py` blocks raw adb/connected commands that skip the lock, touch other packages or change global settings.
